# Dark Waters example

"Dark Waters" is a photographic project by Paolo Dalprato. The example report analyzes ten black-and-white photographs of the sea. The collection has no intentional sequence.

## Included files

- [portfolio-analysis-project-dark-waters.pdf](portfolio-analysis-project-dark-waters.pdf) is the complete illustrated report in English, with 23 pages.
- [dark-waters-photograph-06.jpeg](dark-waters-photograph-06.jpeg) reproduces photograph 06, originally identified as `06_MG_0718_3b.jpg`. It is the report's cover photograph and the repository README preview.

## Provenance

Paolo supplied the existing Italian report `portfolio-analysis-project-dark-waters.pdf` as an example for this repository. The repository example is an English translation of that report, prepared on 11 October 2026. It preserves the analysis, photograph identifiers, complete images, and image placement. A cover note identifies the English translation.

The preview JPEG was extracted from the supplied PDF without resampling or aesthetic alteration. Its dimensions are 1000 by 665 pixels. Its use as a cover does not establish an opening photograph or an authorial sequence.

The example illustrates the analytical approach and report format. It was not generated by independently running the revised skill on the portfolio. The English translation was checked for page count, complete-image reproduction, image placement, title, footer, and page layout.
